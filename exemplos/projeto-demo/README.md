# Publicações: contrato fictício do exemplo

R1: Somente Editor pode salvar uma publicação.
R2: O título deve conter entre 1 e 80 caracteres, inclusive.
R3: Uma gravação recusada não altera os dados; uma gravação aceita persiste para a próxima leitura.

Dados em memória, sem banco, rede, credenciais ou serviços externos.
O runner valida regras com assertions reais e grava resultados individuais no arquivo exclusivo da rodada.
